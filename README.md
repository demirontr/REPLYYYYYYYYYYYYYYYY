# Reply Hackathon

Next.js 16 + TypeScript + Tailwind CSS.

## Kurulum

Gerekenler: [Node.js](https://nodejs.org) (20+) ve [Git](https://git-scm.com).

```bash
git clone https://github.com/demirontr/REPLYYYYYYYYYYYYYYYY.git
cd REPLYYYYYYYYYYYYYYYY
npm install
npm run dev
```

Tarayıcıda http://localhost:3000 adresini aç.

## Yapı

- `src/app/page.tsx`: Ana sayfa (buradan başla)
- `src/app/layout.tsx`: Ortak layout, fontlar
- `src/app/api/...`: API route'ları buraya (`route.ts`)
- `public/`: Görseller

## Takım çalışması

```bash
git pull                       # başlamadan önce
git add . && git commit -m "..."
git push
```

Çakışmayı azaltmak için herkes ayrı dosyada çalışsın.
